Entry for the [One-Line Laugh Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2) bounty on make.fun — one original funny line about everyday life, judged head-to-head by an AI judge.

## The line

> My phone hit 1%, so I whispered 'stay with me' — and it died mid-sentence, like it had somewhere better to be.

## How it works

`main.py` (Python stdlib only) writes that single line — 110 characters, no trailing newline — to `/output/entry.txt`. Deterministic: the same line on every run, no randomness, no network.

```bash
python3 main.py
cat /output/entry.txt
```
